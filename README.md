# Drawing App

## 🎨 Overview

Drawing App is an interactive web-based drawing application developed using HTML, CSS, and JavaScript. It provides a digital canvas where users can create artwork using various drawing tools, colors, and brush sizes directly within their browser.

The project demonstrates the power of the HTML5 Canvas API and showcases practical implementations of drawing functionality, event handling, and dynamic user interactions. It is an excellent learning resource for developers interested in graphics programming and front-end web development.

## ✨ Features

* Freehand drawing tool
* Multiple color selection options
* Adjustable brush sizes
* Eraser functionality
* Shape drawing tools
* Clear canvas option
* Save artwork as an image
* Real-time drawing experience
* Responsive and user-friendly interface
* Lightweight and fast performance

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* HTML5 Canvas API

## 🚀 Getting Started

### Prerequisites

To run this project, you only need a modern web browser:

* Google Chrome
* Mozilla Firefox
* Microsoft Edge
* Safari

### Installation

Clone the repository:

```bash
git clone https://github.com/frankpatel1/Drawing-App.git
```

Navigate to the project directory:

```bash
cd Drawing-App
```

Open the application:

```bash
index.html
```

Or simply double-click the `index.html` file to launch the application in your browser.

## 📖 Usage

1. Open the Drawing App in your browser.
2. Select a drawing tool.
3. Choose a color from the palette.
4. Adjust the brush size as needed.
5. Draw freely on the canvas.
6. Use the eraser to remove unwanted strokes.
7. Clear the canvas when starting a new drawing.
8. Save your completed artwork as an image file.
